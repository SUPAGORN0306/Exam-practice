# Smart Practice — เว็บฝึกทำข้อสอบปรนัยส่วนตัว

แอปนี้เป็นเครื่องมือฝึกทำข้อสอบที่ใช้คนเดียว ทำงานในเบราว์เซอร์ทั้งหมด ข้อมูลเก็บใน `localStorage` ของเครื่องนั้น (ไม่มีการส่งข้อมูลออกนอกเครื่อง)

## 1. วิธีเปิดใช้งานในเครื่อง

1. ดาวน์โหลด/แตกไฟล์โฟลเดอร์โปรเจกต์
2. ดับเบิลคลิก `index.html`
3. เปิดด้วยเบราว์เซอร์ทั่วไป (Chrome, Edge, Firefox, Safari)

## 2. วิธีนำขึ้น GitHub Pages (ทีละขั้น)

1. สร้าง repo ใหม่แบบ **Public** บน GitHub
2. อัปโหลดไฟล์ทั้งโฟลเดอร์ (รวม `index.html` ที่ราก)
3. ไปที่ **Settings → Pages**
4. เลือก **Deploy from a branch** → branch `main` → โฟลเดอร์ `/ (root)` → Save
5. รอระบบสร้างลิงก์ แล้วเปิดใช้งานได้

> **คำเตือน:** repo เป็นสาธารณะ ห้ามใส่ข้อสอบจริงหรือข้อมูลส่วนตัวลงใน repo ข้อสอบของผู้ใช้อยู่ใน `localStorage` ของเครื่องเท่านั้น

## 3. วิธีเพิ่มข้อสอบ 3 วิธี

1. **ผ่านฟอร์ม:** ไปที่เมนู "ข้อสอบ" → "เพิ่ม/แก้ไข" → กรอกแล้วกด "บันทึก"
2. **นำเข้าไฟล์:** ไปที่ "นำเข้า/ส่งออก" → เลือกไฟล์ `.json` หรือวาง JSON ลงช่อง → ตรวจสอบ → "นำเข้าเฉพาะข้อที่ถูกต้อง"
3. **ให้ AI ร่าง:** กดปุ่ม "คัดลอกพรอมต์สำหรับให้ AI ร่างข้อสอบ" → วางใน AI → คัดลอก JSON ที่ได้มาวางในช่องนำเข้า
