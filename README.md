# Smart Practice — เว็บฝึกทำข้อสอบปรนัยส่วนตัว

## 1. วิธีเปิดใช้งานในเครื่อง
ดับเบิลคลิก `index.html` เปิดด้วยเบราว์เซอร์ทั่วไป (Chrome, Edge, Firefox, Safari)

## 2. วิธีนำขึ้น GitHub Pages
1. สร้าง repo ใหม่แบบ **Public** บน GitHub
2. อัปโหลดไฟล์ทั้งโฟลเดอร์ (รวม `index.html` ที่ราก)
3. **Settings → Pages → Deploy from a branch → main / (root) → Save**
4. รอระบบสร้างลิงก์

> **คำเตือน:** repo เป็นสาธารณะ ห้ามใส่ข้อสอบจริงหรือข้อมูลส่วนตัวลงใน repo

## 3. วิธีเพิ่มข้อสอบ 3 วิธี
1. ผ่านฟอร์ม: "ข้อสอบ" → "เพิ่ม/แก้ไข"
2. นำเข้าไฟล์: "นำเข้า/ส่งออก" → `.json` หรือวาง JSON
3. ให้ AI ร่าง: กด "คัดลอกพรอมต์สำหรับให้ AI ร่างข้อสอบ"
